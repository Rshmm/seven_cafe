# کافه هفت

وب‌اپ سفارش کافه با رابط فارسی و راست‌به‌چپ است. همهٔ داده‌ها در همان مرورگر ذخیره می‌شوند و برای همگام‌سازی دو تب از `storage` event استفاده می‌شود.

## اجرا

```bash
npm run dev
```

سپس این مسیرها را باز کنید:

- مشتری: `http://localhost:4173/?table=7`
- آشپزخانه: `http://localhost:4173/kitchen`
- حالت تست آشپزخانه: `http://localhost:4173/kitchen?demo=1`

برای تست دو تب، مشتری و آشپزخانه را روی همین دامنه باز کنید. ثبت سفارش، تغییر وضعیت و تایمر باید بدون رفرش در تب دیگر دیده شود. حالت `demo=1` دکمهٔ افزودن سفارش نمونهٔ ۱۶ دقیقه‌ای را فعال می‌کند.

## بررسی

```bash
npm run check
npm run build
```

بررسی‌های بالا ایستایی فایل‌ها و ساخت خروجی `dist/` را بررسی می‌کنند. رفتار تب‌ها، لمس دکمه‌ها و نمایش موبایل را باید در مرورگر به‌صورت دستی بررسی کرد.

## محدودیت ذخیره‌سازی

این نسخه بک‌اند، دیتابیس، حساب کاربری یا پرداخت ندارد. سفارش‌ها در `localStorage` و سبد خرید، میز و شناسه‌های سفارش همان تب در `sessionStorage` نگهداری می‌شوند؛ پاک‌شدن داده‌های مرورگر، داده‌ها را حذف می‌کند.
